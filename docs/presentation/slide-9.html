Sécurité Cloud

Sécurisation de l’infrastructure AWS

Focus

Protection de l'infrastructure

Ce qui a été mis en place

IAM / IRSA

Rôles AWS dédiés pour les services Kubernetes.

Security Groups

Séparation des accès entre ALB, EKS et base de données.

WAF AWS

Filtrage des requêtes malveillantes avant l’application.

Secrets Manager

Préparé dans Terraform, mais laissé désactivé pour garder une démo stable.

Objectifs de la sécurisation

Réduire la surface d’attaque

Limiter les accès réseau et les permissions AWS au strict nécessaire.

Protéger l’exposition web

Filtrer les requêtes malveillantes en amont grâce au WAF.

Ce que cela apporte au projet

  • Permissions AWS plus propres et mieux isolées
  • Cloisonnement réseau entre ALB, EKS et base de données
  • Protection applicative contre les attaques web courantes
  • Base prête pour intégrer Secrets Manager et d’autres renforcements
